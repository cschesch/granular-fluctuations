# BLS CES source snapshot

`ce.data.0.AllCESSeries.txt.gz` is a lossless gzip copy of the BLS CES data file.
`ce.industry.txt` and `tree.csv` define the industry hierarchy used by the loader.
The loader accepts either the plain or compressed source.

Source files are available from https://download.bls.gov/pub/time.series/ce/.
The decompressed SHA256 is `82f6c731eeee5c0f9657cd89e76b63667b2a10897ba0c1c1ad9c7c23cf2306bf`.
