# Metropolitan GDP

Original Esquierro and Da Silva [Granular Cities workbook](https://doi.org/10.6084/m9.figshare.21702203.v1),
distributed through Figshare under CC BY 4.0.

`DatasetsGranularCities.xlsx` supplies metropolitan GDP levels. The application
uses annual GDP growth for 2003–2019 and fixed 2002 GDP weights, rather than the
source paper's GDP-per-capita outcome and population weights.

The loader is [code/applications/granular_cities/panel.py](../../code/applications/granular_cities/panel.py).
