# US trade

The four UN Comtrade snapshots contain 19,098 original records for US exports
and imports by product or partner, 1995–2024. The JSON file identifies partner
areas. Supplied with attribution to UN Comtrade under its allowance for free
extraction services with up to 100,000 records. See the
[redistribution policy](https://uncomtrade.org/docs/re-dissemination-of-data/).
