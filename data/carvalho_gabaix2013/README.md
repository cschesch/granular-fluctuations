# Carvalho and Gabaix (2013)

`source.zip` preserves the complete original AEA archive recovered from its
September 2015 Internet Archive capture. Its URL and SHA-256 are in
`source.json`.

The application in this repository uses a public BEA–BLS proxy constructed
from the files in `data/bea_klems/`. The original Carvalho–Gabaix archive is
included for reference; it is not the input used for this application.

The analysis code is in [code/applications/carvalho_gabaix/](../../code/applications/carvalho_gabaix/).
