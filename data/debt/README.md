# Country debt

The September 2026 [Global Macro Database](https://www.globalmacrodata.com/)
snapshot retains all observations and the eleven original columns read by the
loader. Public debt comes from GMD; private nonfinancial debt comes from the
IMF Global Debt Database 2025 workbook, with GMD exchange rates.

The GMD terms permit data used in a paper's replication package with attribution.
The IMF workbook retains IMF attribution. See [GMD terms](https://www.globalmacrodata.com/license.html)
and [IMF terms](https://www.imf.org/en/About/copyright-and-terms).
